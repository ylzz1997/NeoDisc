# NeoDisc icon

`neodisc.png` is the source artwork for the desktop icon. It has a transparent exterior and a macOS-style rounded-square base. The Windows `.ico`, macOS `.icns`, and PNG sizes in `src-tauri/icons` are generated with `npm run tauri icon -- assets/neodisc.png`.

Created with the built-in imagegen tool. Final design prompt: flatten the original CD icon into a front-facing, rounded graphite square with an ivory disc, broad amber and muted teal sectors, a simple inner ring and center hole; transparent exterior; no text, bevels, metal texture or heavy shadows.
